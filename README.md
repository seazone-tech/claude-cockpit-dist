# Regente — downloads

Instaladores do Regente (antes Claude Sessões), o app que organiza as sessões do Claude Code em cards.

- Windows: https://github.com/seazone-tech/regente-dist/releases/latest/download/regente-setup.exe
- Mac Apple Silicon: https://github.com/seazone-tech/regente-dist/releases/latest/download/regente-arm64.dmg
- Mac Intel: https://github.com/seazone-tech/regente-dist/releases/latest/download/regente-x64.dmg
- Todas as versões: https://github.com/seazone-tech/regente-dist/releases

O app instalado lê o `latest.yml` / `latest-mac.yml` da release mais recente e avisa quando há versão nova;
nada instala sozinho. No Mac, na primeira abertura: clique direito → Abrir (o app não é assinado).
O código fica no repositório privado `seazone-tech/regente`.
